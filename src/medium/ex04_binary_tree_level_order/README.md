# Exercise 4: Level Order Traversal

### Requirements
- Method: `public static java.util.List<java.util.List<Integer>> levelOrder(TreeNode root)`
- Traversal by depth level from top to bottom, left to right.
- Complexity: $O(N)$ time, $O(N)$ space.

### Examples (LeetCode Style)

**Example 1:**
```text
Input: root = [3, 9, 20, null, null, 15, 7]
Output: [[3], [9, 20], [15, 7]]
```

**Example 2:**
```text
Input: root = [1]
Output: [[1]]
```

**Example 3:**
```text
Input: root = []
Output: []
```
