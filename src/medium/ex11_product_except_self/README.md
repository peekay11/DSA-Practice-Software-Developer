# Exercise 11: Product of Array Except Self

### Requirements
- Method: `public static int[] productExceptSelf(int[] nums)`
- Must run in $O(N)$ time WITHOUT using the division operation.
- $O(1)$ extra space (output array does not count as extra space).

### Examples (LeetCode Style)

**Example 1:**
```text
Input: nums = [1, 2, 3, 4]
Output: [24, 12, 8, 6]
```

**Example 2:**
```text
Input: nums = [-1, 1, 0, -3, 3]
Output: [0, 0, 9, 0, 0]
```
