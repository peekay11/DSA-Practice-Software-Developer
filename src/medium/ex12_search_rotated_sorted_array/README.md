# Exercise 12: Search in Rotated Sorted Array

### Requirements
- Method: `public static int search(int[] nums, int target)`
- Given an array sorted in ascending order and rotated at an unknown pivot, return index of `target` or -1.
- Time Complexity: Strictly $O(\log N)$.

### Examples (LeetCode Style)

**Example 1:**
```text
Input: nums = [4, 5, 6, 7, 0, 1, 2], target = 0
Output: 4
```

**Example 2:**
```text
Input: nums = [4, 5, 6, 7, 0, 1, 2], target = 3
Output: -1
```

**Example 3:**
```text
Input: nums = [1], target = 0
Output: -1
```
