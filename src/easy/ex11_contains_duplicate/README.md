# Exercise 11: Contains Duplicate

### Requirements
- Method: `public static boolean containsDuplicate(int[] nums)`
- Returns `true` if any element appears at least twice.
- If `nums` is null or length < 2, return `false`.
- Complexity: $O(N)$ time, $O(N)$ space.

### Examples (LeetCode Style)

**Example 1:**
```text
Input: nums = [1, 2, 3, 1]
Output: true
```

**Example 2:**
```text
Input: nums = [1, 2, 3, 4]
Output: false
```

**Example 3:**
```text
Input: nums = [1, 1, 1, 3, 3, 4, 3, 2, 4, 2]
Output: true
```
