# Exercise 3: Trapping Rain Water

### Requirements
- Method: `public static int trap(int[] height)`
- Calculate trapped rain water elevation map.
- Complexity: $O(N)$ time, $O(1)$ space using two pointers.

### Examples (LeetCode Style)

**Example 1:**
```text
Input: height = [0, 1, 0, 2, 1, 0, 1, 3, 2, 1, 2, 1]
Output: 6
Explanation: 6 units of rain water are trapped.
```

**Example 2:**
```text
Input: height = [4, 2, 0, 3, 2, 5]
Output: 9
```
