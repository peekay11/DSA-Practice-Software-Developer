# Exercise 7: N-Queens

### Requirements
- Method: `public static int totalNQueens(int n)`
- Return number of distinct solutions to the n-queens puzzle.
- Time Complexity: Backtracking with branch pruning.

### Examples (LeetCode Style)

**Example 1:**
```text
Input: n = 4
Output: 2
Explanation: There are two distinct solutions to the 4-queens puzzle.
```

**Example 2:**
```text
Input: n = 1
Output: 1
```
