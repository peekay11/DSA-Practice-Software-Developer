# Exercise 12: First Missing Positive

### Requirements
- Method: `public static int firstMissingPositive(int[] nums)`
- Smallest missing positive integer.
- Strict Constraints: $O(N)$ time, strictly $O(1)$ auxiliary space.

### Examples (LeetCode Style)

**Example 1:**
```text
Input: nums = [1, 2, 0]
Output: 3
Explanation: The numbers in the range [1,2] are all in the array.
```

**Example 2:**
```text
Input: nums = [3, 4, -1, 1]
Output: 2
Explanation: 1 is in the array but 2 is missing.
```

**Example 3:**
```text
Input: nums = [7, 8, 9, 11, 12]
Output: 1
Explanation: The smallest positive integer 1 is missing.
```
