# Exercise 10: Serialize and Deserialize Binary Tree

### Requirements
- Methods:
  - `public String serialize(TreeNode root)`
  - `public TreeNode deserialize(String data)`

### Examples (LeetCode Style)

**Example 1:**
```text
Input: root = [1, 2, 3, null, null, 4, 5]
Output: [1, 2, 3, null, null, 4, 5]
Explanation: Serialization produces a string representation and deserialization reconstructs the original tree.
```

**Example 2:**
```text
Input: root = []
Output: []
```
